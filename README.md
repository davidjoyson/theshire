# The Shire

Info page for The Shire, a tea estate cottage stay in Wayanad, Kerala — linking out to the Airbnb listing.

**Live site:** https://theshire.in

## What's in this repo

- `index.html` — the full page (single file, HTML + CSS, no build step)

## Editing

Open `index.html` and search for `TODO` comments — they mark everything that still needs real content:

- Airbnb listing link (two places: hero button and closing section)
- Photo gallery (currently placeholder blocks — swap in `<img>` tags)
- Amenities list
- Getting There directions and travel times
- Booking details (sleeps, bedrooms, check-in/out times)

Commit and push changes to `main` — GitHub Pages redeploys automatically within a minute or two.
